# 📰 News Article Classification using Naive Bayes

A simple Machine Learning web app built with Streamlit that classifies news articles into multiple categories using the Naive Bayes algorithm.

---

## 🚀 Features

- Real-time news classification
- Machine Learning based prediction
- Interactive Streamlit web interface
- Text preprocessing using CountVectorizer
- Fast and lightweight model
- Simple and user-friendly UI

---

## 🧠 Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn

---

## 📂 Dataset

BBC News Classification Dataset

Dataset Source:  
https://raw.githubusercontent.com/ronaldleonardo/Data_Transformer_Datasets/refs/heads/main/bbc_text_cls.csv

---

## 📌 Categories

The model predicts news into the following categories:

- Business
- Entertainment
- Politics
- Sport
- Tech
- Science

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/news-classifier.git
```

### 2️⃣ Move into Project Folder

```bash
cd news-classifier
```

### 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Streamlit Application

```bash
streamlit run app.py
```

---

## 📷 Application Preview

Users can enter any news headline or article text and instantly get the predicted news category.

---

## 📈 Machine Learning Workflow

1. Load Dataset
2. Extract Features from Text
3. Convert Text into Numerical Vectors
4. Train Naive Bayes Model
5. Predict User Input Category
6. Display Prediction in Streamlit UI
